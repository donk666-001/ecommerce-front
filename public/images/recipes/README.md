## 使用说明

### 当前状态
目前这些图片文件尚未添加，组件中使用的是占位路径。在实际部署时，需要：

1. **添加真实图片**：将对应的食谱图片放入此目录
2. **图片规格建议**：
   - 尺寸：400x300px 或相同比例
   - 格式：JPG/PNG/WebP
   - 大小：每张图片控制在200KB以内
   - 质量：中等质量，适合网页展示

### 临时解决方案
在开发阶段，可以使用以下方式：

1. **使用在线图片服务**：
   ```typescript
   // 修改组件中的图片路径为在线URL
   image: 'https://via.placeholder.com/400x300?text=莲子百合粥'
   ```

2. **使用本地占位图**：
   - 创建简单的纯色背景图片
   - 或使用CSS渐变背景替代

3. **移除图片显示**：
   - 暂时注释掉图片相关代码
   - 仅显示文字信息

### 图片命名规范
- 使用小写字母
- 单词间用连字符分隔
- 描述性命名，便于识别
